**As a** learner, **I want to** install Danesh on a clean Windows or macOS machine and have it keep my data durable, private and safe from crashing engines, **so that** I can trust it with my documents and study history.

Output: Tier B evidence folders, finalized ADRs 0001-0003, `evidence/EVIDENCE-INDEX.md`.
</objective>
