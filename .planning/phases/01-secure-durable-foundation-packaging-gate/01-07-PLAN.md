## Phase Goal

**As a** learner, **I want to** install Danesh on a clean Windows or macOS machine and have it keep my data durable, private and safe from crashing engines, **so that** I can trust it with my documents and study history.

<objective>

Purpose: the security boundary every later slice relies on; PLAT-02's edge cases become executable via the core ipc-validation feature.
Output: logging package, pure validation envelope and client tracker, Core RPC server, Main window/user-data/egress modules, unit tests and E2E bindings.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Renderer → preload → Core | Untrusted page input crosses into the single DB writer |
| Core ↔ Main control channel | Process-level control messages |
| Core ↔ engine hosts | Host replies are untrusted (engines parse untrusted documents later) |
| Chromium networking → internet | Default Chromium features can phone home |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-15 | Denial of Service | Oversized or malformed IPC payloads | high | mitigate | UTF-8 byte limits per method checked before parsing in preload and Core; exact method lookup; strict zod schemas |
| T-01-16 | Information Disclosure | Payload or user content in logs | high | mitigate | Logger field allowlist, 200-char cap, no `input` key; tests assert Persian/ZWNJ/bidi/surrogate payload text never appears |
| T-01-17 | Elevation of Privilege | Navigation, window.open, webviews, permission prompts | high | mitigate | will-navigate/will-redirect prevent, window-open deny, webview attach prevent, permission handlers deny by default |
| T-01-18 | Tampering | Second instance opening the same library concurrently | high | mitigate | requestSingleInstanceLock after the library path is final; second instance quits |
| T-01-46 | Information Disclosure | Chromium background egress (spellcheck dictionaries, etc.) | high | mitigate | webRequest cancel on all sessions, spellchecker disabled, counter + host-only log |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages; frozen lockfile from Plan 01-02 |
</threat_model>
