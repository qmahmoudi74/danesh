## Phase Goal

**As a** learner, **I want to** install Danesh on a clean Windows or macOS machine and have it keep my data durable, private and safe from crashing engines, **so that** I can trust it with my documents and study history.

<objective>
Contain crashes (PLAT-04): a supervisor that treats every exit it did not request as a crash (V8 OOM exits 0, research R8), restarts hosts and Core with integer backoff, opens a circuit on crash loops, kills hung hosts via a heartbeat watchdog, and hands failures to the job kernel so only the in-flight task is retried or quarantined — while the window, Core and other hosts keep running. Add the Core-failed start-up state with «راه‌اندازی دوباره».

Purpose: the crash-isolation half of the phase goal ("safe from crashing engines").
Output: pure backoff/policy/supervisor (TDD with fake processes and a fake clock, D-21), Electron spawner, fault injection, Core respawn and port re-brokering, UI states and E2E coverage.
</objective>
