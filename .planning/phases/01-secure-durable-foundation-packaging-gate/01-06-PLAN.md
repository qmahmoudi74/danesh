| Boundary | Description |
|----------|-------------|

| Core report data → DOM | Check details include paths and engine output hashes |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-45 | Spoofing | Untrusted frame invoking `danesh:shell` | high | mitigate | `isTrustedShellOrigin` check on `senderFrame.url` before any handler; zod validation of method and input |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages; frozen lockfile from Plan 01-02 |
