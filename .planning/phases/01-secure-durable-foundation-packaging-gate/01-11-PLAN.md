## Phase Goal

**As a** learner, **I want to** install Danesh on a clean Windows or macOS machine and have it keep my data durable, private and safe from crashing engines, **so that** I can trust it with my documents and study history.

<objective>
Make user data durable and version-safe (PLAT-06, PLAT-07, D-14): a forward-only, checksum-guarded migration runner with `PRAGMA user_version`, a verified pre-migration backup with keep-last-3 retention, refusal of databases written by a newer Danesh via a read-only probe, and a read-only recovery state after a failed migration — with the start-up states visible on Home exactly as in UI-SPEC.

Purpose: every future data upgrade builds on this format; restorability is proven at the storage layer (UI-SPEC A-07: no restore button in Phase 1).
Output: storage runner and backup modules, library layout, Core boot states, Home banners, unit/Gherkin/E2E coverage.
</objective>
