## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-23 | Tampering | Probe asset substitution | high | mitigate | Commit-pinned URLs, size + SHA-256 verified while streaming, atomic rename; mismatch fails the build; no runtime downloads |
| T-01-24 | Tampering (legal) | GPL code embedded in an engine binary | high | mitigate | sherpa-onnx excluded; TTS via onnxruntime-node with hand-fed phoneme ids; binary-licenses manifest reviewed; license scan in CI |
| T-01-25 | Elevation of Privilege | Engine host gaining DB or network access | high | mitigate | Hosts import no storage or network modules (dependency-cruiser); Main/renderer cannot import engines; hosts receive only asset paths/bytes and return results |
| T-01-47 | Denial of Service | A hung or crashing probe blocking the System check | medium | mitigate | 90 s per-engine timeout, crash isolated to its row, report always written |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages; probe assets are not npm packages and go through the pinned-hash fetch above |
